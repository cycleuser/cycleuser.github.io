基于本地模型的编程学习辅助环境搭建完整指南

发布于 Mon 06 October 2025 | 标签 基于本地模型的编程学习辅助环境搭建完整指南

于劲郭 于劲郭

最近这些年接触了很多学习编程的新手同学，发现有一些学习路径可能会让学习者遇到明显瓶颈：

•一部分人严格依赖教科书和纸质资料，内容陈旧、缺乏实战，学的东西可能适合应付考试，但在真实开发中很难衔接；  •另一些人面对官方技术文档的英文内容心生畏惧，转而求助于某些广告泛滥、信息混杂的中文网站（比如某些以“DN”结尾的平台），结果获取的是二手、陈年甚至错误的内容；  •还有一些人大量收藏教学视频，刷完就忘，即使记住了概念，也不知道如何动手实现，更谈不上灵活运用；  •也有一部分人过度依赖在线 AI 工具，让模型生成大量代码，看似“什么都能做”，实则对底层原理一无所知——一旦生成结果不符合预期，既无从调试，也难以优化，并不算是真有开发能力。

要突破这些困境，关键不在于工具本身，而在于思维方式的转变： 人应当始终是项目的总设计师与架构师。这意味着：

•在动手前，先想清楚整体目标、模块划分与技术选型；  •对每一个实现细节，都要追问“为什么这么做”“是否有更优解”“背后的机制是什么”；  •把复杂问题拆解为若干可独立处理的子任务，再借助工具高效完成具体实现；  •在学习时，主动利用 AI 的联网检索、多语言翻译与知识整合能力，从宏观、前沿、一手的资料（如官方文档、开源项目、技术博客）中构建认知框架，而不是沉湎于碎片化技巧或过时教程。

而要支撑这种“以我为主、AI为辅”的学习与开发范式，就需要一个本地化、可定制、数据自主的技术环境。本文推荐的组合正是为此设计：

•Void 作为主力开发终端，提供干净、高效、可扩展的编码与调试体验；  •Ollama 在本地运行轻量大模型（如 qwen3:0.6b 和 qwen3:4b），无需联网即可获得即时编程辅助；  •Cherry Studio 用于导入官方文档、技术文章、个人笔记、网页快照等一手学习资料，构建专属知识库，让 AI 回答始终基于你信任的内容。

本文即围绕这一实践路径展开，以新手比较常用的  Windows 系统为例，粗略介绍如何在其中安装 Ollama、Cherry Studio 与  Void，并配置适用于编程学习的本地模型组合。内容涵盖模型拉取（包括主模型与嵌入模型）、学习资料导入、开发环境插件配置等，供新手参考。

1、安装 Ollama

Ollama 是一个专为本地运行大语言模型设计的工具，支持一键拉取和运行多种开源模型，允许在断网、隐私敏感或网络不稳的环境下本地运行一些开源的大语言模型，依然能获得可靠的编程辅助。

安装步骤：

访问 Ollama 官网下载页面： https://ollama.com/download/OllamaSetup.exe （该链接自动提供最新版 Windows 安装程序）

双击下载完成的 OllamaSetup.exe 文件，按提示点击 “Install”。

安装完成后，Ollama 会自动以后台服务形式运行，无需额外操作。

验证是否安装成功： 按 Win + R，输入 cmd 打开命令提示符，执行：

ollama --version

若返回版本号（如 0.1.48），说明安装成功。

2、获取模型

为了适配不同学习阶段的需求，建议同时配置两个主模型和一个嵌入模型：

•qwen3:0.6b：超轻量版本，响应极快，适合快速解释语法、检查拼写、生成简单函数或单元测试；  •qwen3:4b：标准版本，逻辑推理更强，适合分析报错日志、设计类结构、讲解并发模型等复杂任务；  •qwen3-embedding:0.6b：用于将学习资料转换为向量，支撑 Cherry Studio 中的语义检索。•qwen3-embedding:4b：比前面的更强一点，如果显卡有8G以上显存，其实上面的主模型和这里的嵌入模型都可以用qwen3:8b 和qwen3-embedding:8b。

什么是嵌入（Embedding）： 嵌入是将一段文本（如一段 Markdown或者JSON文档）转换为一串数字向量的技术。语义相近的内容，其向量在空间中距离更近。通过嵌入，Cherry Studio  能在导入的成百上千页资料中，精准定位与当前问题最相关的段落，再交给主模型生成回答——整个过程完全离线，数据不出本地，既安全又可靠。

获取模型：

以管理员身份打开 PowerShell（Win + S 搜索 “PowerShell” → 右键 → 以管理员身份运行）。

拉取主模型：

ollama pull qwen3:0.6bollama pull qwen3:4b.

拉取嵌入模型：

ollama pull qwen3-embedding:0.6b.

验证主模型是否可用：

ollama run qwen3:0.6b "Python 中如何用列表推导式生成偶数？"

若返回类似 [x for x in range(10) if x % 2 == 0] 的简洁代码，说明模型工作正常。

3、下载并安装 Cherry Studio

Cherry Studio 是一个本地知识库对话工具，可以将官方文档、GitHub  项目 README、技术博客、个人笔记、网页快照导入其中，系统会自动建立索引。基于知识库的提问，模型回答会基于知识库中已经提供的资料，降低了回答的幻觉（并不能彻底避免幻觉的存在，所以还是得小心）。

安装步骤：

访问 Cherry Studio 官网下载页面：https://www.cherry-ai.com/download

点击 “Windows” 按钮下载安装包（如 Cherry-Studio-Setup-x64.exe）。

双击安装文件，按向导完成安装。

首次启动后，进行初始化配置：

•点击 “Connect to Ollama”；•在 LLM Model 中填写 qwen3:4b（用于深度问答）或 qwen3:0.6b（用于快速响应）；•在 Embedding Model 中填写 qwen3-embedding:0.6b；•点击 “Create Workspace” 创建名为 My-Learning 的工作区。

导入资料：

•拖入 .md 笔记、.pdf 官方指南、.txt 代码示例；•粘贴网页 URL（如 https://docs.python.org/3/tutorial/），Cherry Studio 会自动提取正文；•系统将在后台完成解析与索引（首次可能需几分钟）。

索引完成后，即可提问。例如：

“根据我导入的 Django 文档，如何自定义用户模型？” 回答将引用你提供的资料，帮助你建立“从权威来源理解问题”的习惯。

4、下载并安装 Void 终端

Void 是一款现代化、可扩展的 Windows 终端，界面简洁、启动迅速，支持多标签页与插件系统，非常适合作为日常编程学习的主力开发环境。它让你专注于“写代码”本身，而不是被繁杂的 IDE 功能干扰。

安装步骤：

访问 Void 官网或 GitHub Releases 页面： https://voideditor.com/download-beta.

下载最新版安装程序（如 Void-Installer.exe）。

双击运行安装程序，按提示完成安装（建议勾选“创建桌面快捷方式”）。

启动 Void，记得要选择LocalLLM，以便于使用Ollama提供的模型。

5、在 Void 中安装 Python 与 Markdown 插件

为支撑“边学边写、边写边查”的学习闭环，建议在 Void 中启用对 Python 和 Markdown 的增强支持。

安装步骤：在 Void 中按下 Ctrl + Shift + P 打开命令面板，然后输入 Extensions: Install 并回车，打开插件市场。

搜索并安装以下两个插件：

•Python Language Support 提供语法高亮、括号匹配、错误提示，以及按 F5 快速运行当前脚本；•Markdown Preview Plus 支持实时预览 .md 文件，方便查看学习笔记、项目说明或文档草稿。

安装完成后，重启 Void 使插件生效。

验证功能：

•新建 debug.py，输入 print("Step 1: Understand the problem")，按 F5 应在终端中运行；•新建 learning-notes.md，输入 ## 模块化设计原则，按 Ctrl+K V 应弹出格式化预览。

6、疑难问题如何解决

场景 推荐做法
遇到陌生概念 先用浏览器搜索该技术的关键词（如 “FastAPI dependency injection official site”），优先点击官网或 GitHub 链接；将找到的官方文档 URL（如 https://fastapi.tiangolo.com/tutorial/dependencies/）复制到 Cherry Studio，系统会自动抓取正文并建立索引；之后再提问：“用通俗语言解释依赖注入，结合我导入的 FastAPI 文档。”
调试报错信息 将完整错误信息粘贴到搜索引擎，筛选出  Stack Overflow 高票回答或官方 Issue 讨论；若涉及框架行为，务必找到对应版本的官方文档 URL 一并导入 Cherry  Studio；随后提问：“根据我导入的 Flask 2.3 文档和错误日志，这个 Working outside of application context 是怎么回事？”
设计程序结构 先在纸上或思维导图中明确目标与模块划分；针对每个模块，搜索其最佳实践（如 “Python logging best practices official”），导入 PEP、官方指南或知名开源项目 README；再让 qwen3:4b 基于这些资料生成符合规范的骨架代码。
学习新框架 不要直接看短视频或聚合站教程。先访问其官网（通常在  GitHub 主页或项目首页有链接），找到 Quickstart、Tutorial 和 Core Concepts 页面；将这些核心文档的  URL 批量导入 Cherry Studio；之后通过提问逐步深入，例如：“对比我导入的 LangChain 和 LlamaIndex  的入门文档，它们在文档加载方式上有何异同？”
验证 AI 生成代码 在 Void 中运行代码，观察行为；若结果不符预期，不要盲目修改，而是回到 Cherry Studio，导入相关模块的官方 API 文档；再追问：“根据 Python 官方文档，itertools.chain() 和列表拼接在内存使用上有何区别？为什么这里推荐用前者？”

上述流程的核心在于：你始终掌控信息源的质量与范围。AI   不再是神秘的“黑箱答案提供者”，而是基于你主动筛选并导入的一手资料（如官方文档、权威教程、开源项目说明）的“可信解释者”。这不仅有效规避了网络上泛滥的二手、过时甚至错误信息，更在实践中锻炼你识别权威来源、组织知识结构的能力——而这，正是优秀程序员不可或缺的底层素养。

通过前述步骤，你已构建起一个以自己为主导、AI 为辅助的本地编程学习环境：Void 作为干净高效的“工作台”，支撑日常编码、调试与文档预览；Ollama 作为离线运行的“本地助手”，提供即时、私密且可定制的编程建议；Cherry Studio 则充当你的“知识中枢”，将你精心收集的权威资料转化为可问答、可追溯的个人知识库，确保每一次交互都有据可依。

这套环境的真正价值，不在于让 AI 替你写代码，而在于助你更高效地理解原理、验证假设、构建系统。当你能清晰定义目标、追问设计合理性、规划验证路径——比如“我要实现什么？”“为什么这样设计最优？”“下一步该测试哪个边界条件？”——AI 就真正成为你手中的工具，而非思维的替代品。编程学习的本质，终究是培养拆解问题、抽象建模、迭代验证的能力。工具只是加速器，而你，永远是站在架构顶端的设计师。
