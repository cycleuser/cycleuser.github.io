大学新生可能遇到的各种常见缩写速查简介

发布于 Sat 25 July 2026 | 标签 education freshman abbreviations university

先说清楚：这篇文章不是提倡用英文缩写。恰恰相反。

钱钟书有个牙缝韭菜的典故——说话的时候牙齿上沾着一片韭菜，自己不知道，别人看着难受。中文里夹英文缩写也是这个道理。你说了一堆，听的人还得逐个解码，听得很累。能不混用就不混用，该说中文说中文。

但问题是你拦不住别人用。老师随口就说「这个 DDL 之前交上来」，同学说「你是不是被 PUA 了」，群里讨论买电脑全是「SSD 要 1T 的」「内存 16G 够不够」。你不认识这些缩写，就真听不懂，不是你的问题，是信息被挡住了。

所以这里把大学里常见又容易让人懵住的缩写按领域列出来。不是为了让你学着用，是为了你碰到的时候能一眼认出是什么意思。

校园日常

这几个是大学生活里出现频率最高的，先记这几个就行。

缩写 英文全称 解释
AKA Also Known As 又名、也就是
CEO / CFO / CTO Chief Executive / Financial / Technology Officer 首席执行官 / 首席财务官 / 首席技术官。C 打头的基本都是最高层
CIO Chief Information Officer 首席信息官。管企业信息化建设的高级职位。注意甄别，有的机构可能会以 CIO 为名头行骗，对不熟悉的邀约保持警惕
DDL Deadline 截止日期。大学生最怕的词之一，作业、论文、申报材料都有 DDL
FYI For Your Information 供你参考。邮件、消息里转发信息时常带的前缀
HR Human Resources 人力资源。管招聘、薪资、考核的部门
KOL Key Opinion Leader 关键意见领袖。就是网红、大 V、某个领域里说话有分量的人
KPI Key Performance Indicator 关键绩效指标。衡量你做得好不好的数字指标
OKR Objectives and Key Results 目标与关键结果。一种定目标和追踪执行的管理方法
PR Public Relations 公共关系。管对外形象和媒体沟通。注意 GitHub 上 PR 是 Pull Request（合并请求），两个意思完全不同
PUA Pick-Up Artist 原指以不良手段搭讪操控他人。现在多指精神操控、持续打压让人自我怀疑的行为。被导师 PUA、被老板 PUA，就是说被人持续贬低打压

学业相关

缩写 英文全称 解释
arXiv Archive（χ 是希腊字母 chi） 预印本论文网站。物理、数学、计算机等学科发正式期刊之前先把论文挂上去，全世界都能免费看。读论文、跟踪前沿研究必知的站点
CET-4 / CET-6 College English Test Band 4 / 6 大学英语四六级。国内本科最基本的英语水平证明
CSSCI Chinese Social Sciences Citation Index 中文社会科学引文索引，简称「C 刊」。文科导师常挂在嘴边的就是它
DOI Digital Object Identifier 数字对象标识符。论文的唯一编号，有了它就能永久定位到一篇文章
EI Engineering Index 工程索引。工科论文的重要收录库，比 SCI 覆盖面更偏工程应用
GPA Grade Point Average 平均绩点。大学成绩的综合评分，满分通常是 4.0。一般 90-100 分对应 4.0，80-89 对应 3.0，70-79 对应 2.0，60-69 对应 1.0，不及格是 0。各校微调不一样，但大致是这个比例。申请研究生或者找工作会看。不过，如果你有很好的学术文章、扎实可靠的软件作品、或者竞赛拿了省一等奖乃至国家级三等奖以上，这些东西都比 GPA 更厉害
GRE Graduate Record Examination 美国研究生入学考试。去北美读研要考这个
IELTS International English Language Testing System 雅思。和托福一样，另一个主流的英语水平考试
ISBN International Standard Book Number 国际标准书号。每本公开出版的书独有的编号，找书、借书、引用都会用到
MOOC Massive Open Online Course 大规模开放在线课程。网上免费的大学课程，比如中国大学 MOOC、Coursera
ORCID Open Researcher and Contributor ID 开放研究者身份识别码。每个研究者的唯一 ID，不管同名同姓还是换了单位，这个码不会变。发论文、投基金都用的到
PDF Portable Document Format 便携式文档格式。不管什么系统打开格式都不乱
PPT PowerPoint 这个不用解释了吧。上课做展示、答辩、汇报都离不开的幻灯片
SCI Science Citation Index 科学引文索引。收录高水平期刊的数据库，发 SCI 论文是很多理工科研究生的目标
TOEFL Test of English as a Foreign Language 托福。去英语国家留学的语言考试

学位与证书

缩写 英文全称 解释
ACCA Association of Chartered Certified Accountants 特许公认会计师。国际会计准则方向的会计证书
BA / BS Bachelor of Arts / Science 文学学士 / 理学学士。你本科毕业拿的就是这个
CFA Chartered Financial Analyst 特许金融分析师。金融行业含金量很高的证书，三级考试通过率很低
CPA Certified Public Accountant 注册会计师。会计行业的核心证书
EMBA Executive MBA 高级管理人员 MBA。给有多年管理经验的人读的，通常不脱产
MA / MS Master of Arts / Science 文学硕士 / 理学硕士
MBA Master of Business Administration 工商管理硕士。工作几年后很多人去读，培养管理能力
MPA Master of Public Administration 公共管理硕士。培养政府部门或非营利组织管理人才
PhD Doctor of Philosophy 哲学博士。最高学位，不限哲学专业，理工科博士也是 PhD
PMP Project Management Professional 项目管理专业人士认证。管理类通用的国际证书

计算机硬件

缩写 英文全称 解释
ARM Advanced RISC Machine 一种低功耗处理器架构，手机、平板、苹果 M 系列芯片都是 ARM 架构的
BIOS Basic Input/Output System 基本输入输出系统。开机时最先启动的那套程序，UEFI 是它的升级版
CPU Central Processing Unit 中央处理器。电脑的大脑，Intel 和 AMD 两家主导
CUDA Compute Unified Device Architecture NVIDIA 的 GPU 并行计算平台。做 AI 训练、科学计算基本都用它
DDR Double Data Rate 双倍数据速率内存。现在主流是 DDR4 和 DDR5，数字越大越快
DirectX Direct eXtension 微软的多媒体和游戏编程接口。Windows 上玩游戏离不开这个
FPGA Field-Programmable Gate Array 现场可编程门阵列。一种可以自己定义电路逻辑的芯片，硬件工程师用得多
GPU Graphics Processing Unit 图形处理器。俗称显卡，做图形渲染和 AI 训练的主力
HBM High Bandwidth Memory 高带宽内存。堆叠封装的内存，带宽极高，AI 加速卡（比如 NVIDIA H100）上用的
HDD Hard Disk Drive 机械硬盘。便宜容量大，适合存不常用的文件
HDMI High-Definition Multimedia Interface 高清多媒体接口。连显示器、投影仪用的
IO Input / Output 输入输出。所有数据进出设备的统称
NPU Neural Processing Unit 神经网络处理器。专门跑 AI 推理的芯片，手机和笔记本里越来越常见
NVMe Non-Volatile Memory Express 非易失性内存高速传输协议。现在最快的 SSD 接口协议，比 SATA 快好几倍
Oculink Optical Copper Link 外置 PCIe 连接方案。把显卡或者硬盘通过一根线接到笔记本外面，带宽比雷电高
OpenCL Open Computing Language 开放的并行计算框架，不绑特定厂商，AMD、Intel、NVIDIA 都支持
OpenGL Open Graphics Library 跨平台的 2D/3D 图形渲染接口。CAD、游戏引擎都会用到
PCIe Peripheral Component Interconnect Express 高速外设总线。显卡、SSD、网卡都插在这个接口上，现在主流是 PCIe 4.0 和 5.0
PSU Power Supply Unit 电源。把 220V 交流电转成电脑用的低电压直流电
RAM Random Access Memory 随机存取存储器。也就是内存，程序运行时临时存放数据的地方，断电就没了
RISC Reduced Instruction Set Computer 精简指令集。一种 CPU 设计思路，指令简单但执行快。ARM 就是 RISC 架构的代表
ROM Read-Only Memory 只读存储器。数据写进去后断电不丢
SATA Serial Advanced Technology Attachment 串行 ATA。硬盘接口，机械硬盘和老一点的固态硬盘都用这个，比 NVMe 慢但便宜
SSD Solid State Drive 固态硬盘。比机械硬盘快很多，现在装系统基本都是用 SSD
TPU Tensor Processing Unit 谷歌的 AI 加速芯片，张量处理器。普通用户摸不到，但学 AI 的话会经常听说
USB Universal Serial Bus 通用串行总线。就是那个插 U 盘的接口
VRAM Video RAM 显存。显卡上专用的内存
Vulkan — 新一代跨平台图形与计算 API，比 OpenGL 效率更高。AMD 开源贡献出来的，名叫 Mantle 的前身
x86 — Intel 搞出来的处理器架构，PC 和服务器上用得最多的 CPU 指令集。AMD 和 Intel 的桌面 CPU 都是 x86 兼容的
x86-64 / AMD64 — x86 的 64 位扩展，由 AMD 率先推出，Intel 后来跟进。现在几乎所有桌面电脑的 CPU 都支持这个

软件与网络

缩写 英文全称 解释
API Application Programming Interface 应用程序编程接口。不同软件之间交换数据的协议和规则
CLI Command-Line Interface 命令行界面。黑框框里敲命令，程序员必备
CDN Content Delivery Network 内容分发网络。把网页、图片、视频缓存到离你最近的服务器上，加快访问速度
CSV Comma-Separated Values 逗号分隔值。表格数据纯文本存储的格式，Excel 能开
DNS Domain Name System 域名系统。把网址（如 baidu.com）转成 IP 地址的服务
GUI Graphical User Interface 图形用户界面。你看到的带窗口、按钮、图标的界面都是 GUI
HTML HyperText Markup Language 超文本标记语言。写网页用的标记语言
HTTP / HTTPS HyperText Transfer Protocol (Secure) 网页传输协议。HTTPS 多了加密层，现在几乎都是 HTTPS 了
IDE Integrated Development Environment 集成开发环境。写代码的软件，比如 VS Code、PyCharm、IDEA
IoT Internet of Things 物联网。让冰箱、灯泡、门锁联网的技术统称
IP Internet Protocol 互联网协议。给每个联网设备分配的地址
JSON JavaScript Object Notation 一种轻量数据交换格式。程序之间传数据用得多
LaTeX — 学术论文排版工具，数学公式渲染特别好，理工科写论文几乎必学
Markdown — 轻量级标记语言。用简单的符号就能排版，写 README、记笔记、写博客都用得到
OOP Object-Oriented Programming 面向对象编程。一种编程思想，Java、Python、C++ 都支持
OS Operating System 操作系统。Windows、macOS、Linux 都是 OS
P2P Peer-to-Peer 点对点。不经过中心服务器，设备之间直接传数据。BT 下载、PCDN 都基于这个
PCDN P2P Content Delivery Network P2P 内容分发网络。利用大量用户设备互相传数据来加速分发，比传统 CDN 省带宽成本
SQL Structured Query Language 结构化查询语言。和数据库打交道用的，增删改查全靠它
URL Uniform Resource Locator 统一资源定位符。就是网址
VPN Virtual Private Network 虚拟私人网络。加密你的网络流量，用来访问受限资源或保护隐私
VR / AR Virtual Reality / Augmented Reality 虚拟现实 / 增强现实。VR=戴头盔沉浸虚拟世界，AR=在现实画面里叠虚拟信息
XML eXtensible Markup Language 可扩展标记语言。和 JSON 差不多，以前更流行

云服务

缩写 英文全称 解释
BaaS Backend as a Service 后端即服务。帮你搭好服务器端，你只写前端就行，比如 Firebase、Supabase
DaaS Desktop as a Service 桌面即服务。云端给你一台虚拟电脑，远程连上去用
IaaS Infrastructure as a Service 基础设施即服务。给你虚拟机、硬盘、网络，你自己在上面装系统配环境，比如阿里云 ECS、AWS EC2
MaaS Model as a Service 模型即服务。把训练好的大模型包装成 API 给你调用，不用自己部署，按用量付费
PaaS Platform as a Service 平台即服务。给你一个配好的开发环境，你只写代码不碰服务器，比如 Heroku、Vercel
SaaS Software as a Service 软件即服务。不用装软件，打开网页就能用，比如飞书、石墨文档、Notion

版本控制与开源

缩写 英文全称 解释
CLA Contributor License Agreement 贡献者许可协议。给开源项目贡献代码前要签的协议，把代码版权授予项目方
LGTM Looks Good To Me 我看没问题。代码审查时常用的批准语
PR Pull Request 合并请求。你在自己分支改完代码，发起一个请求让主项目合进去。GitHub 上最常见的协作操作
RFC Request for Comments 征求意见。提出一个方案让大家讨论，常见于技术标准制定
WIP Work In Progress 工作中。代码还没写完，先提交上去占个位置

RX / TX Receiver / Transmitter 接收机 / 发射机
S (如 3S、6S) Series 锂电池串联数。3S=3 节串联，电压乘 3
SBUS Serial BUS Futaba 发明的一种串行总线协议，遥控器接收机和飞控之间用
UART Universal Asynchronous Receiver/Transmitter 串口通信。飞控接 GPS、数传等外设用的
VTX Video Transmitter 图传发射机。把相机画面无线传回地面

电子与通信

Bluetooth — 蓝牙。短距离无线通信
DSP Digital Signal Processor 数字信号处理器。专门处理音频、视频、传感器信号的芯片

LCD Liquid Crystal Display 液晶显示器。最常见的屏幕类型

NFC Near Field Communication 近场通信。刷卡、刷手机用的短距离无线技术
OLED Organic LED 有机发光二极管。屏幕的一种，黑色不发光的
PCB Printed Circuit Board 印刷电路板。所有电子元器件焊在上面的那块绿板子
RFID Radio Frequency Identification 射频识别。门禁卡、物流标签用的
SoC System on Chip 片上系统。把 CPU、GPU、内存等集成在一颗芯片上，比如手机处理器
Wi-Fi Wireless Fidelity 无线局域网。就是无线上网

NGO Non-Governmental Organization 非政府组织。境外 NGO 在华活动需依法登记。遇到以 NGO 名义拉拢参与敏感项目的，注意甄别，防范被利用从事涉密或危害国家安全的活动，主动规避风险，保护好自己和家人
NPO Non-Profit Organization 非营利组织。和 NGO 类似，不追求利润的社会组织。同样需注意甄别境外背景，保护个人信息
OCR Optical Character Recognition 光学字符识别。把图片里的文字提取出来，扫描件转文字用的
QA / QC Quality Assurance / Quality Control 质量保证 / 质量控制。测试产品确保不出问题的
R&D Research and Development 研发。企业中搞研究的部门
ROI Return on Investment 投资回报率。投了多少钱带来了多少收益
RSVP Répondez s'il vous plaît（法语） 请回复。邀请函上常见的，要你确认去不去
SOP Standard Operating Procedure 标准作业流程。规定一件事具体怎么做的文档
TBA To Be Announced 待公布
TBD To Be Determined 待定
