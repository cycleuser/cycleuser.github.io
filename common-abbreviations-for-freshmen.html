大学新生常见的缩写都在这了，别再挨个查了

发布于 Mon 20 July 2026 | 标签 education freshman abbreviations university

刚上大学，是不是经常遇到一堆英文缩写听不懂？老师随口就说「你的 GPA 要提一提」，学长说「考个 CFA 对就业有帮助」，买电脑的时候被问「要多大 SSD」。

这些东西其实不多，整理出来看一遍就明白了。我按领域分了几张表，以后碰见哪个不认识的回来翻一下就成。

学业相关

缩写 英文全称 解释
GPA Grade Point Average 平均绩点。大学成绩的综合评分，通常满分 4.0 或 5.0，申请研究生、找工作都会看
GRE Graduate Record Examination 美国研究生入学考试。去北美读研要考这个
TOEFL Test of English as a Foreign Language 托福。去英语国家留学的语言考试
IELTS International English Language Testing System 雅思。和托福一样，另一个主流的英语水平考试
CET-4 / CET-6 College English Test Band 4 / 6 大学英语四六级。国内本科最基本的英语水平证明
SCI Science Citation Index 科学引文索引。收录高水平期刊的数据库，发 SCI 论文是很多理工科研究生的目标
EI Engineering Index 工程索引。工科论文的重要收录库，比 SCI 覆盖面更偏工程应用
CSSCI Chinese Social Sciences Citation Index 中文社会科学引文索引，简称「C 刊」。文科导师常挂在嘴边的就是它
DOI Digital Object Identifier 数字对象标识符。论文的唯一编号，有了它就能永久定位到一篇文章
MOOC Massive Open Online Course 大规模开放在线课程。网上免费的大学课程，比如中国大学 MOOC、Coursera
PPT PowerPoint 这个不用解释了吧。上课做展示、答辩、汇报都离不开的幻灯片
PDF Portable Document Format 便携式文档格式。不管什么系统打开格式都不乱

学位与证书

缩写 英文全称 解释
BA / BS Bachelor of Arts / Science 文学学士 / 理学学士。你本科毕业拿的就是这个
MA / MS Master of Arts / Science 文学硕士 / 理学硕士
PhD Doctor of Philosophy 哲学博士。最高学位，不限哲学专业，理工科博士也是 PhD
MBA Master of Business Administration 工商管理硕士。工作几年后很多人去读，培养管理能力
EMBA Executive MBA 高级管理人员 MBA。给有多年管理经验的人读的，通常不脱产
MPA Master of Public Administration 公共管理硕士。培养政府部门或非营利组织管理人才
CFA Chartered Financial Analyst 特许金融分析师。金融行业含金量很高的证书，三级考试通过率很低
CPA Certified Public Accountant 注册会计师。会计行业的核心证书
ACCA Association of Chartered Certified Accountants 特许公认会计师。国际会计准则方向的会计证书
PMP Project Management Professional 项目管理专业人士认证。管理类通用的国际证书

计算机硬件

缩写 英文全称 解释
CPU Central Processing Unit 中央处理器。电脑的大脑，Intel 和 AMD 两家主导
GPU Graphics Processing Unit 图形处理器。俗称显卡，做图形渲染和 AI 训练的主力
RAM Random Access Memory 随机存取存储器。也就是内存，程序运行时临时存放数据的地方，断电就没了
ROM Read-Only Memory 只读存储器。数据写进去后断电不丢
SSD Solid State Drive 固态硬盘。比机械硬盘快很多，现在装系统基本都是用 SSD
HDD Hard Disk Drive 机械硬盘。便宜容量大，适合存不常用的文件
PSU Power Supply Unit 电源。把 220V 交流电转成电脑用的低电压直流电
IO Input / Output 输入输出。所有数据进出设备的统称
USB Universal Serial Bus 通用串行总线。就是那个插 U 盘的接口
HDMI High-Definition Multimedia Interface 高清多媒体接口。连显示器、投影仪用的
BIOS Basic Input/Output System 基本输入输出系统。开机时最先启动的那套程序，UEFI 是它的升级版
VRAM Video RAM 显存。显卡上专用的内存

软件与网络

缩写 英文全称 解释
OS Operating System 操作系统。Windows、macOS、Linux 都是 OS
API Application Programming Interface 应用程序编程接口。不同软件之间交换数据的协议和规则
GUI Graphical User Interface 图形用户界面。你看到的带窗口、按钮、图标的界面都是 GUI
CLI Command-Line Interface 命令行界面。黑框框里敲命令，程序员必备
IDE Integrated Development Environment 集成开发环境。写代码的软件，比如 VS Code、PyCharm、IDEA
VPN Virtual Private Network 虚拟私人网络。加密你的网络流量，用来访问受限资源或保护隐私
DNS Domain Name System 域名系统。把网址（如 baidu.com）转成 IP 地址的服务
URL Uniform Resource Locator 统一资源定位符。就是网址
IP Internet Protocol 互联网协议。给每个联网设备分配的地址
HTTP / HTTPS HyperText Transfer Protocol (Secure) 网页传输协议。HTTPS 多了加密层，现在几乎都是 HTTPS 了
HTML HyperText Markup Language 超文本标记语言。写网页用的标记语言
JSON JavaScript Object Notation 一种轻量数据交换格式。程序之间传数据用得多
CSV Comma-Separated Values 逗号分隔值。表格数据纯文本存储的格式，Excel 能开
XML eXtensible Markup Language 可扩展标记语言。和 JSON 差不多，以前更流行

无人机/航模相关

缩写 英文全称 解释
FC / FCS Flight Control System 飞行控制系统。也就是飞控板，无人机的大脑
IMU Inertial Measurement Unit 惯性测量单元。集成加速度计和陀螺仪，感知姿态
ESC Electronic Speed Controller 电调。控制电机转速的器件，飞控发信号给它，它驱动电机转
GPS Global Positioning System 全球定位系统。给飞控提供位置和速度
GNSS Global Navigation Satellite System 全球导航卫星系统。GPS、北斗、GLONASS 等的统称
RTK Real-Time Kinematic 实时动态定位。厘米级精度的定位技术
VTX Video Transmitter 图传发射机。把相机画面无线传回地面
RX / TX Receiver / Transmitter 接收机 / 发射机
SBUS Serial BUS Futaba 发明的一种串行总线协议，遥控器接收机和飞控之间用
PPM Pulse Position Modulation 另一种遥控信号编码方式，比 SBUS 老
PWM Pulse Width Modulation 脉宽调制。控制舵机和电调的基本信号
ADC Analog-to-Digital Converter 模数转换器。飞控用它检测电池电压电流
UART Universal Asynchronous Receiver/Transmitter 串口通信。飞控接 GPS、数传等外设用的
LiPo Lithium Polymer 锂聚合物电池。航模无人机最常用的电池类型
S (如 3S、6S) Series 锂电池串联数。3S=3 节串联，电压乘 3
P (如 2P) Parallel 锂电池并联数。2P=2 节并联，容量翻倍
BEC Battery Eliminator Circuit 降压电路。从主电池分出一路低压给飞控、接收机供电

电子与通信

缩写 英文全称 解释
AC / DC Alternating Current / Direct Current 交流电 / 直流电。电池出来是直流，插座出来是交流
LED Light-Emitting Diode 发光二极管。小小的指示灯，也很省电
OLED Organic LED 有机发光二极管。屏幕的一种，黑色不发光的
LCD Liquid Crystal Display 液晶显示器。最常见的屏幕类型
PCB Printed Circuit Board 印刷电路板。所有电子元器件焊在上面的那块绿板子
IC Integrated Circuit 集成电路。也就是芯片
SoC System on Chip 片上系统。把 CPU、GPU、内存等集成在一颗芯片上，比如手机处理器
MCU Microcontroller Unit 单片机。小型的处理器，嵌入式设备常用
NFC Near Field Communication 近场通信。刷卡、刷手机用的短距离无线技术
RFID Radio Frequency Identification 射频识别。门禁卡、物流标签用的
Bluetooth — 蓝牙。短距离无线通信
Wi-Fi Wireless Fidelity 无线局域网。就是无线上网

医学与健康

缩写 英文全称 解释
BMI Body Mass Index 身体质量指数。体重(kg)÷身高(m)²，衡量是否超重
CT Computed Tomography 计算机断层扫描。用 X 光从多角度拍然后合成三维图像
MRI Magnetic Resonance Imaging 磁共振成像。没有辐射的扫描方式，看软组织更清楚
ICU Intensive Care Unit 重症监护室
ECG / EKG Electrocardiogram 心电图
EEG Electroencephalogram 脑电图
ADHD Attention Deficit Hyperactivity Disorder 注意力缺陷多动障碍。俗称多动症

其他常见缩写

缩写 英文全称 解释
DIY Do It Yourself 自己动手做。比如自己装电脑、自己焊东西
FAQ Frequently Asked Questions 常见问题解答。几乎所有产品文档都有这一栏
ETA Estimated Time of Arrival 预计到达时间
RSVP Répondez s'il vous plaît（法语） 请回复。邀请函上常见的，要你确认去不去
ASAP As Soon As Possible 尽快
FYI For Your Information 供你参考。转发信息时常用的前缀
TBD To Be Determined 待定
TBA To Be Announced 待公布
AKA Also Known As 又名
B2B / B2C Business to Business / Consumer 企业对企业 / 企业对消费者。商业模式的分类
NGO Non-Governmental Organization 非政府组织
NPO Non-Profit Organization 非营利组织

这里列的只是一部分，大学四年里你还会陆续遇到更多的缩写。原则很简单：每次遇到不认识的，当场查一下，三秒钟的事，但心里有数了下次就不会慌。 别攒着不查，攒多了就真不愿意查了。
